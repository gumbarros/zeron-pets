# Composer Cat

Adapted from the original Zeron development plugin: a blue-eyed Siamese pixel cat with seal-brown points and a tiny tail perched on the message box, with occasional blinks, tail flicks and ear twitches. Respects system Reduce Motion and does not intercept the mouse.

Source: https://github.com/zeronsh/zeron/tree/main/apps/zgx/plugins-dev/composer-cat
License: MIT (see LICENSE).

Allow Composer Cat in Settings → Plugins to enable it. Turn it off there to remove the cat.

Uses only `ui.add`; no network, commands, or message access.
